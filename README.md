# شركة عمران التجارية — متجر الألعاب والهدايا

متجر إلكتروني خفيف وسريع للتوريد والتوزيع: ألعاب أطفال، عرائس ومجسمات، ألعاب تعليمية، بالونات وهدايا.
يدعم **التسعير المزدوج** (قطاعي / جملة) وإرسال الطلبات مباشرة عبر **واتساب**.

مبني باستخدام **Next.js App Router** و **TypeScript** و **Tailwind CSS v4** بتخطيط عربي كامل من اليمين إلى اليسار،
ويُصدَّر كموقع ثابت بالكامل (`output: "export"`) بدون أي خادم.

---

## معمارية الصفحات الأربع

| الصفحة | المسار | المحتوى |
| --- | --- | --- |
| الرئيسية | `src/app/page.tsx` | البنر الرئيسي، شبكة الأقسام، أبرز العروض، شريط الثقة، شبكة الفروع |
| الكتالوج | `src/app/products/page.tsx` | تصفية فورية حسب القسم + مفتاح الجملة/القطاعي + شبكة منتجات |
| تفاصيل المنتج | `src/app/products/[id]/page.tsx` | معرض صور، حاسبة كمية ديناميكية، طلب مباشر عبر الواتساب |
| إتمام الطلب | `src/app/checkout/page.tsx` | نموذج مختصر، ملخص تكلفة شفاف، إرسال الطلب عبر الواتساب |

كل صفحات المنتجات تُولَّد مسبقاً عبر `generateStaticParams` (٢٣ صفحة ثابتة إجمالاً).

## المزايا الأساسية

### ١. لغة عربية وتخطيط RTL

- الصفحة معرّفة بـ `lang="ar"` و `dir="rtl"` على مستوى الجذر.
- استخدام خصائص منطقية (`start` / `end` / `ps` / `pe`) بدل اليمين واليسار الثابتين.
- خط **Cairo** المتغيّر مستضاف محلياً (ملفان يغطيان كل الأوزان) بدون أي طلبات لخوادم خارجية.
- الأرقام والأسعار داخل عنصر `.num` بخاصية `direction: ltr` و `unicode-bidi: isolate`.

### ٢. منع التمرير الأفقي (Horizontal Overflow Guard)

في `src/app/globals.css`:

- `overflow-x: clip` و `max-width: 100%` على `html` و `body` فقط.
- `min-width: 0` و `box-sizing: border-box` على كل العناصر لمنع تمدد عناصر الـ flex/grid.
- `max-width: 100%` على الوسائط والجداول، و `overflow-wrap: anywhere` على النصوص والروابط الطويلة.
- الفلاتر ومصغّرات الصور داخل `.scroll-x` بتمرير أفقي محلي لا يؤثر على الصفحة.

> ملاحظة: تجنّبنا `max-width: 100%` على `*` لأنها تكسر العناصر المطلقة والأيقونات؛ القاعدة مطبّقة على الجذر والوسائط فقط.

### ٣. مفتاح التسعير المزدوج

- مفتاح «قطاعي / جملة» في الكتالوج وصفحة المنتج والسلة.
- التبديل يحدّث فوراً: بطاقات المنتجات، حاسبة الكمية، ملخص التكلفة، ونص رسالة واتساب.
- في وضع الجملة يظهر **سعر الدستة (١٢ قطعة)** و **سعر الكرتونة**، وتصبح خطوة الكمية بالكرتونة.
- الحد الأدنى للجملة لا يقل أبداً عن دستة كاملة (`siteConfig.operations.wholesaleMinUnits`).
- الاختيار محفوظ في `localStorage` ومتزامن بين تبويبات المتصفح.

### ٤. الأداء (Zero-Bloat)

- بدون أي مكتبة أنيميشن أو إدارة حالة خارجية — التفاعلات الدقيقة بـ CSS مباشر (`.press` / `.lift`).
- الصفحة الرئيسية وصفحات المنتجات **مكوّنات خادم بالكامل** (لا JavaScript للتفاعل الأساسي).
- الكتالوج يُرسَم كاملاً في HTML الثابت، ثم يُطبَّق `?cat=` بعد الترطيب عبر `useSyncExternalStore` — أفضل لمحركات البحث وللـ LCP.
- `next/image` مع `sizes` محسوبة لكل موضع، و `priority` لأول صفّ فقط.
- تحميل مسبق للخطوط (`preload`) وصور المنتجات الأولى.

### ٥. جودة الكود

- بناء إنتاجي نظيف بلا أخطاء أنواع، وواجهات TypeScript صارمة (`strict` + `noUncheckedIndexedAccess`).
- حالة السلة عبر `useSyncExternalStore` لتفادي أي اختلاف بين رسم الخادم والمتصفح (hydration mismatch).
- ٢٥ اختباراً آلياً تغطي منطق التسعير والسلة ورسالة واتساب والترطيب والإعدادات.

## تخصيص البيانات

- **بيانات الشركة والفروع والتنقل:** `src/lib/site.ts` — كل النصوص وأرقام التواصل والفروع ونصوص التنبيهات في مكان واحد.
- **المنتجات:** `src/lib/products.ts` — كل صنف يحمل سعرين (`retailPrice` / `wholesalePrice`) وبيانات تعبئة (`packaging`).
- **الأقسام:** `src/lib/categories.ts`.
- **الصور:** الصور الحالية توضيحية بصيغة SVG داخل `public/products`. عند توفر صور فوتوغرافية، ضعها في نفس المجلد وحدّث مسارات `images`.
