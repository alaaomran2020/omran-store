# دفعة إصلاح الاعتماديات التطويرية

**التاريخ:** 26 أغسطس 2026

## نطاق المشكلة

كشف `npm audit` ثغرتين عاليتين في الاعتماديات التطويرية: `brace-expansion` عبر مسارات `minimatch`، و`js-yaml` عبر `@eslint/eslintrc`. لم تكن الثغرات ضمن اعتماديات الإنتاج.

## الإصلاح المطبق

تم تشغيل `npm audit fix --package-lock-only` ثم إعادة تثبيت نظيفة من lockfile. أصبحت الإصدارات الفعلية هي `brace-expansion@1.1.18` و`brace-expansion@5.0.9` و`js-yaml@4.3.2`. لم يتم إجراء ترقية شاملة أو تعديل في منطق التطبيق.

كما أضيف `test-results/` و`playwright-report/` إلى `.gitignore` لمنع إدخال traces ولقطات الاختبارات المؤقتة إلى المستودع.

## التحقق

نجح `npm audit --audit-level=high` بلا ثغرات. نجحت اختبارات الوحدة وعددها 21، وفحوص TypeScript وESLint، وبناء الإنتاج، واختبارات المتصفح وعددها 10 على سطح المكتب ومحاكاة الهاتف.

## التراجع

الدفعة محصورة في الاعتماديات وقواعد Gitignore، ويمكن التراجع عنها بإعادة نشر commit السابق لها دون أي أثر على بيانات المنتجات أو الصفحات.
