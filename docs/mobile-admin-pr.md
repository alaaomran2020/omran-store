## ملخص

إضافة لوحة إدارة داخلية مهيأة للموبايل على `/admin` لإدارة كتالوج شركة عمران التجارية. الواجهة العامة لا تعرض رابط اللوحة ولا بياناتها.

## ما تم

- تسجيل دخول خاص بالفريق عبر أسماء مستخدمين وكلمات مرور محفوظة بصيغة hash في أسرار Vercel.
- عرض المنتجات والبحث فيها.
- تعديل الاسم والكود والأسعار والقسم والوصف والتوفر والتمييز.
- إضافة منتج جديد.
- زر حفظ محلي داخل الجلسة وزر **حفظ ونشر** ينشئ commit في مصدر الكتالوج المركزي.
- حماية الكتابة عبر SHA لمنع الكتابة فوق تعديل عضو آخر.
- تحويل الكتالوج الحالي ذي 12 منتجاً إلى `src/data/catalog-products.json` مع الحفاظ على نفس الحقول.
- جدولة نشر الساعة 12 ظهراً و12 ليلاً بتوقيت القاهرة عبر Deploy Hook.
- منع فهرسة `/admin` و`/api/admin`.
- إيقاف workflow الخاص بـ GitHub Pages لأن اللوحة تحتاج تشغيل Vercel الخادمي؛ GitHub يبقى مستودع الكود والنسخ والتراجع.
- إزالة قسم مصدر بيانات Instagram واللغة القديمة من الواجهة العامة وتوحيد الهوية حول شركة عمران التجارية — لعب أطفال - هدايا.

## إعداد ما قبل التفعيل

يجب ضبط `ADMIN_SESSION_SECRET` و`ADMIN_USERS_JSON` و`ADMIN_GITHUB_TOKEN` في Vercel، وإضافة `VERCEL_DEPLOY_HOOK_URL` إلى أسرار GitHub للجدولة. عند غياب الإعدادات تظل لوحة الإدارة مغلقة افتراضياً.

## التحقق

- 21 اختبار وحدة ناجح.
- 16 اختبار متصفح ناجح.

- بناء Vercel الخادمي ناجح.
