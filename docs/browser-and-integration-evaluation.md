# تقييم اختبارات المتصفح والتكاملات

**التاريخ:** 26 أغسطس 2026

## اختبارات المتصفح

أضيفت اختبارات Playwright مستقلة تحت `e2e/` وتغطي الصفحة الرئيسية، دعوات الكتالوج وواتساب، البحث، المعاينة السريعة، رابط المنتج الدقيق، التنقل المحمول، الصفحات القانونية، وصفحة 404. تعمل الاختبارات على سطح مكتب ومحاكاة هاتف باستخدام Chromium، وتُشغّل محلياً عبر `npm run test:e2e` وعلى GitHub Actions قبل رفع artifact النشر.

نجحت الجولة الأخيرة في البيئتين: **10 اختبارات ناجحة** خلال نحو 12 ثانية. كما بقيت اختبارات الوحدة الحالية ناجحة وعددها 21، ونجح فحص TypeScript وESLint وبناء الإنتاج.

## معالجة صورة Instagram

استُبدل عنصر HTML الخام `<img>` بمكوّن `next/image` باستخدام `fill` و`sizes` و`unoptimized`. هذا يحافظ على روابط Instagram الخارجية وعلى التصدير الثابت الحالي، ويزيل تحذير ESLint دون إدخال خدمة صور أو تغيير شكل البطاقات.

## محاولة قراءة بيانات الأحداث

تم العثور على مشروع Vercel المرتبط بالمستودع ومعرّف Web Analytics، ثم أُجري استعلام read-only للأحداث المخصصة خلال آخر 30 يوماً. رفضت Vercel الطلب بحالة `402 Payment Required` مع رسالة تفيد بأن الوصول إلى Custom Events يحتاج Enterprise أو Pro. لذلك لا توجد حالياً عينة حقيقية يمكن استخدامها لحساب معدل نقر واتساب أو مقارنة المنتجات والفلاتر.

هذه النتيجة تعني أن التوصية الحالية ليست أن التكاملات غير مطلوبة، بل أن **الحاجة لم تثبت بعد**. لا ينبغي إضافة لوحة إدارة أو WhatsApp Cloud API اعتماداً على تخمينات؛ فقياس النقرات الحالي يثبت نية التواصل فقط ولا يثبت نتيجة المحادثة أو المبيعات.

## القرار المرحلي

| الخيار | القرار الحالي | سبب القرار |
|---|---|---|
| لوحة إدارة | تأجيل | لا توجد بيانات استخدام أو حجم تحديثات تثبت أن إدارة المنتجات خارج GitHub أصبحت عنق زجاجة |
| WhatsApp Cloud API | تأجيل | الموقع يحتاج حالياً رابط استفسار؛ لا يوجد دليل على حاجة إلى صندوق وارد أو webhooks أو إدارة محادثات |
| القياس الحالي | الإبقاء عليه | منخفض المخاطر، مجهّل، ولا يغيّر تجربة المستخدم |
| الخطوة العملية | جمع عينة بيانات قابلة للقراءة | تصدير تقرير Web Analytics للأحداث أو توفير صلاحية قراءة مناسبة، ثم تحليل 14–30 يوماً |

بعد توفر البيانات، يكون معيار الانتقال إلى لوحة إدارة هو وجود تحديثات متكررة من عدة محررين أو أخطاء تشغيلية من تعديل JSON. ويكون معيار WhatsApp Cloud API وجود حجم محادثات يحتاج توزيعاً وسجل حالات وwebhooks، وليس مجرد عدد نقرات مرتفع.

## ملاحظات أمنية

أظهر فحص الإنتاج `npm audit --omit=dev` عدم وجود ثغرات، بينما يظهر الفحص الكامل ثغرتين عاليتين ضمن اعتماديات التطوير غير المستخدمة في الإنتاج، وهما `brace-expansion` و`js-yaml`. ستُعالج هذه الاعتماديات في دفعة منفصلة بعد مراجعة شجرة الاعتماديات، ولا يُنصح بخلطها مع قرار التكامل التشغيلي.
